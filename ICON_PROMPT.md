# Prompt immagini — Layiix TV Sideload

Usa questi prompt con un generatore (DALL·E, Midjourney, Stable Diffusion, Firefly).
Stile: flat moderno, sfondo scuro Layiix `#0B0B12`, accenti viola `#7C4DFF` → ciano `#00E5FF`.

## 1) Icona launcher (512×512, poi adattiva)

```
Minimalist Android launcher icon, flat vector style, dark background #0B0B12:
a modern flat-screen TV silhouette in deep purple #7C4DFF with a glowing cyan
#00E5FF downward arrow entering the screen, subtle wireless signal arcs above,
soft neon glow, rounded square, no text, no letters, clean premium tech look,
high contrast, centered composition
```

Negativo: `photo, realistic, text, letters, watermark, cluttered, 3d render`

## 2) Banner feature graphic (1024×500, per pagina download/Play)

```
Wide feature graphic, dark tech background #0B0B12 with purple-to-cyan gradient
waves: on the left a smartphone, on the right a Samsung-style smart TV, glowing
cyan wireless transfer arcs between them, small floating .wgt package cube icons,
premium minimalist flat illustration, no text, cinematic lighting, 1024x500
```

## 3) Icona alternativa (se la 1 non convince)

```
App icon, rounded square dark #14141F: stylized letter L formed by a play button
and a TV antenna, gradient purple #7C4DFF to cyan #00E5FF, flat, minimal,
glowing edges, no text, vector logo style
```

## Dopo la generazione

- Icona: ritaglia/scala a 512×512 PNG → poi `mipmap-xxxhdpi/ic_launcher.png`
  (o rigenerala vettoriale se sai farlo).
- Banner: `feature-graphic.png` 1024×500 per README/pagina download.
- Non usare loghi Samsung/Tizen: solo forme generiche (TV rettangolare).
